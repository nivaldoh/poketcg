2026-06-28 — reliable model-to-model eval (the "did it get better?" machinery).
- FINDING (verified at the cg ABI): CRN / paired-seed comparison is IMPOSSIBLE here — battle_start
  takes only decks, libcg.so exports no Seed/SRand, the engine seeds its own mt19937 from
  std::random_device (OS entropy). --seed controls only agent-side sampling, never the deal. So the
  old EVAL.md §3 "paired CRN is an upgrade worth making" note was wrong -> corrected; memory added
  (cg-engine-rng-unseedable-crn-infeasible). Self-checkable: identical decks + identical random.seed
  -> divergent battles (probe PASSES: result 1 vs 0, traj len 256 vs 89).
- eval.py: added --mode {battery,gauntlet,sprt}. gauntlet = score one ckpt vs a FROZEN hash-pinned
  anchor pool (random floor / anchor SKILL axis / teacher confound) -> one comparable scalar
  (win% + implied Elo vs anchor). sprt = GSPRT sequential A/B verdict (computer-chess "did this patch
  help?"; fewest games at controlled alpha/beta). New helpers: sha256, anchored_elo (pegs an anchor
  to 0 -> comparable across runs, vs the old per-run mean-anchored fit_elo), sprt (variance shrunk
  toward 0.25 so a short identical streak can't fire a false early verdict), play_match_sequential,
  gauntlet, run_manifest (the comparability contract: ckpt sha256s, search-count, decks, n,
  torch/device/determinism, git commit). Stats fixes: warn below the TRUST_N~200 floor; deck-confounded
  vs-teacher kept OFF the gauntlet skill axis; saturated-vs-random Elo flagged prior-driven;
  torch.use_deterministic_algorithms(warn_only) + CUBLAS_WORKSPACE_CONFIG note.
- Frozen anchor: out/anchor_model0.pth (= model0), sha256 5bf4b8ae...f8c4122 (in EVAL.md §5 + memory).
- eval_agreement.py (new): held-out top-1/top-k move-agreement vs the teacher over a FROZEN decision
  set (built once, since the engine RNG is unseedable; never trained on). The low-variance signal for
  near-identical checkpoints that win-rate can't separate. Smoke (10 teacher games -> 1154 decisions):
  bc_ce 87.2% [85.1-89.0] vs anchor_model0 21.9% [19.6-24.4] (random floor 18.3%) — tight,
  non-overlapping CIs; the 87% matches the prior ~85.7% teacher-agreement figure.
- EVAL.md: new §5 "Reliable A/B comparison" (the written approach: CRN impossible -> gauntlet + SPRT
  + agreement; MDE table; comparability contract), §3 CRN note corrected, modes in §7, renumbered.
  eval-discipline skill: added harness rows + rules (anchored Elo only; gauntlet scalar over a moving
  baseline; SPRT for ship/no-ship; agreement for near-identical).
