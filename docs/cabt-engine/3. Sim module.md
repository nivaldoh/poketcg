sim module
This module defines the low-level interface to the C++ shared library (libcg.so or cg.dll), including initialization, battle bindings, search engine bindings, and card metadata retrieval.

Classes

Globals
The following global objects and bindings are defined at the module level:

lib : Loaded shared library (C++ core)

Function bindings: - GameInitialize - BattleStart - AgentStart - BattleFinish - GetBattleData - Select - VisualizeData - SearchBegin - SearchStep - SearchEnd - SearchRelease - AllCard - AllAttack

Note

These bindings are directly connected to the underlying game engine and not Python-native functions. They are configured using ctypes.
